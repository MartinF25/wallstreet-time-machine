# Career Mode

New careers begin with six-step character creation. Existing careers without an investor profile enter setup once and retain all prior progress. The profile uses the career's existing level and XP.

Career state records the current era, capital, difficulty, carryover mode, XP, level, completed episode IDs, and per-era best score and grade. Progression is sequential.

Career results use the same episode engine as standalone play. Finishing an episode produces a result, applies capital carryover, awards XP, updates statistics, stores the best grade, and unlocks the next era. Levels range from 1 to 10 at 1,000 XP intervals.

The dashboard shows level, XP, capital, all 18 eras, completion state, and spoiler-safe future descriptions. Standalone episodes do not advance the career.
