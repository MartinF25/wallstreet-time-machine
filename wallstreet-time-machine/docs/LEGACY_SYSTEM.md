# Legacy System

The deterministic legacy result also produces a timeless portrait configuration with top badges, signature-style accent, title, and score-based frame treatment.

Legacy is derived deterministically from completed eras, capital preservation, drawdown, benchmark performance, research, strategy consistency, and crisis survival. Signature style follows actual behavior. A defensive Speculator can therefore become a Capital Preserver. Scores range from 0 to 1,000 and titles remain distinct from career level titles.
