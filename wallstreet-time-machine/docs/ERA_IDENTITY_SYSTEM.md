# Era Identity System

The game HUD resolves the current era, mood, crisis treatment, frame, and archetype accent for every active round. Era styling changes atmosphere and portrait treatment while the control layout remains stable.

One investor identity travels through ten visual style groups spanning 1900 to the modern era. Name, face key, gender presentation, archetype, abilities, XP, and gameplay remain constant. Outfit, backdrop, lighting, props, frame, badges, mood, and crisis treatment may change.

The layer order is base identity → era → archetype accent → mood → crisis → badges → frame. All layers resolve deterministically and contain no market or event data.
