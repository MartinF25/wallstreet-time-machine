# Challenge System

The challenge registry has six entries. Panic Survivor, Crash Proof, and Energy Trader are playable through the shared episode engine. War Finance, Dot-Com Discipline, and Liquidity 2008 are explicit coming-soon entries.

Each challenge defines starting capital, difficulty, objective text, and an optional episode. Challenge saves are stored separately from career and standalone episode saves. Completing a challenge updates challenge statistics without unlocking a career era.
