# INTELLIGENCE SYSTEM

Sprint 4 consumers receive the same availability-filtered information through `AgentContext`. Agent output must cite known market, indicator, news, event, portfolio, or strategy evidence.

Central IntelligenceService filters every source by the current game date before building snapshots or read-only IntelligenceContext. Snapshots summarize market, macro, news, risk, watchlist, changed information, quality, and confidence. Confidence describes evidence quality, never forecast accuracy.
