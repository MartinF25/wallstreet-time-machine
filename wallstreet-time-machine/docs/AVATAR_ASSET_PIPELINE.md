# Avatar Asset Pipeline

`AvatarAssetManifest` centralizes base, thumbnail, fallback, era, and mood references plus `PLACEHOLDER`, `GENERATED`, `APPROVED`, or `FINAL` status. Planned directories are `/public/avatars/base`, `/era/{1900,1920,1940,1970,1980,1990,2000,modern}`, and `/legacy`.

Use stable names derived from existing avatar IDs, WebP 4:5 masters, controlled 1:1 crops, and a consistent eye line, camera distance, lighting quality, and framing. Every avatar needs a visual identity key and a written consistency sheet covering face shape, hair, eyes, skin tone, distinguishing features, framing, presentation, and base expression. Assets must depict original fictional people, never celebrity or historical-person lookalikes.
